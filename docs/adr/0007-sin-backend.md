# ADR-07: sin backend propio

- **Estado:** Aceptada
- **Fecha:** 2026-10-24

## Contexto

Se podría centralizar caché o métricas en un servidor.

## Decisión

Todo ocurre en el dispositivo; LRCLIB cumple el rol de backend de letras.

## Motivos y consecuencias

Costo cero, privacidad máxima, menor superficie de ataque.
